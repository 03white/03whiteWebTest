# FlowGraph — 流程图编辑器 PRD

> 版本：v0.1 · 状态：草案（待评审）

## 1. 项目定位

FlowGraph 是一个基于 Web 的轻量流程图编辑器。用户可在空白画布上创建节点、拖拽摆放、拖出连线，组成流程图 / 拓扑图 / 状态图，并将图形**序列化为 JSON**（保存/加载）或**导出为图片**（SVG/PNG）。

技术栈：Vue 3 + Vite + TypeScript，SVG 渲染。

## 2. 目标用户与核心场景

- **用户**：需要快速绘制流程图、架构图、依赖关系图的前端/产品/开发者。
- **核心场景**：空白画布 → 加节点 → 拖拽摆放 → 连线 → 调整形状/文本 → 保存（JSON）/ 导出（图片）。

## 3. MVP 功能清单

| 编号 | 能力 | 说明 |
|------|------|------|
| F1 | 画布缩放/平移 | 滚轮缩放、拖拽空白区平移、背景网格 |
| F2 | 节点增删改拖 | 创建、拖拽移动、选中、删除、编辑文本 |
| F3 | 连线（边） | 从节点锚点拖出，连接到目标节点 |
| F4 | 序列化/反序列化 | 图形保存为 JSON 并可从 JSON 恢复 |
| F5 | 撤销/重做 | 基于命令栈的 undo/redo |
| F6 | 多选/复制粘贴 | 框选/多选、复制、粘贴 |
| F7 | 导出图片 | 导出 SVG 与 PNG |
| F8 | 多节点形状 | 矩形 / 圆角矩形 / 菱形 / 椭圆 等预设形状 |

## 4. 功能详述

### F1 画布缩放/平移
- 滚轮以光标为中心缩放，缩放范围受 config 约束（如 0.2x ~ 4x）。
- 按住空白区（或空格+拖拽）平移画布。
- 背景网格随缩放自适应（网格间距按 zoom 分档）。

### F2 节点增删改拖
- 点击空白创建默认节点；双击节点进入文本编辑；选中后 Delete/Backspace 删除。
- 拖拽移动节点，移动时相连边实时跟随。
- 支持多个预设形状（见 F8）。

### F3 连线（边）
- 从节点锚点拖出，松开到目标节点即建立连线。
- 连线类型：直线 / 折线 / 曲线（MVP 至少支持直线，折线/曲线为增强）。
- 边可带可选文本标签。

### F4 序列化/反序列化
- 图形结构（节点/边/视口）序列化为 JSON，符合 `assets/graph.schema.json`（单一源头）。
- 可从合法 JSON 完整恢复图形（含视口）。

### F5 撤销/重做
- 所有结构变更（增删节点/边、移动、改文本、粘贴等）均通过**命令模式**记录。
- Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z（或 Ctrl+Y）重做。

### F6 多选/复制粘贴
- 空白区拖拽框选；Ctrl/Cmd 点选追加；Ctrl/Cmd+A 全选。
- Ctrl/Cmd+C/V 复制粘贴选中项（粘贴位置偏移，避免重叠）。

### F7 导出图片
- 导出 SVG（矢量，无损）与 PNG（位图，按当前视口或全部内容）。
- 导出边界 = 内容包围盒 + 边距。

### F8 多节点形状
- 预设形状：矩形（rect）、圆角矩形（rounded）、菱形（diamond）、椭圆（ellipse）。
- 形状枚举与默认尺寸纳入 `assets/` 源头（design-tokens / configs）。

## 5. 非目标（YAGNI，本版不做）

- 多人协作 / 实时同步。
- 服务端存储、账号体系、分享链接。
- 复杂样式面板（自由改色/改字体/阴影等，仅预设形状 + 基础样式）。
- 自动布局（auto-layout）与路由算法优化。
- 流程图语义校验（连通性、类型校验等）。

## 6. 技术选型（初版，详见 02Design）

| 项 | 选择 | 理由 |
|----|------|------|
| 框架 | Vue 3 + Vite + TS | 既定技术栈 |
| 渲染 | SVG | 命中检测、DOM 事件、SVG/PNG 导出天然契合 |
| 状态 | Composable + reactive 模型（必要时 Pinia） | 先轻量，避免过早抽象 |
| 撤销重做 | 命令模式（command stack） | 结构清晰、易测试 |
| 序列化 | JSON Schema（`assets/graph.schema.json`） | 单一源头，供 harness 校验 |

## 7. 验收标准（MVP Done）

1. 能创建/移动/删除/改文本至少 4 种形状节点。
2. 能拖出连线连接任意两节点，连线随节点移动。
3. 画布可缩放/平移，网格正常。
4. 图可存为 JSON 并完整恢复。
5. undo/redo 覆盖所有结构变更。
6. 可多选并复制粘贴。
7. 可导出 SVG 与 PNG。
8. `assets/` 资源源头通过 harness schema/契约校验。
