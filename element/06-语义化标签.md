# 06 · 语义化标签与页面骨架

这是 HTML 篇最重要的一课,因为它决定了你**能不能看懂真实项目**。

## div 与 span:没有语义的"盒子"
- `<div>`:块级容器(独占一行),用来分区、包裹一组内容。
- `<span>`:行内容器,包一小段文字。

它们**本身没有含义**,纯粹用来配合 CSS 布局。老网页里全是 `<div>`,看着就头大。

## 语义化标签:有含义的盒子
HTML5 引入了一批"有身份"的标签,它们其实就是**特殊的 div**,但名字告诉你这块是干什么的:

| 标签 | 含义 | 通常放什么 |
|------|------|-----------|
| `<header>` | 页头 | logo、网站标题、导航 |
| `<nav>` | 导航 | 菜单链接(内部常是 `ul>li`) |
| `<main>` | 主内容 | 页面核心内容(每页仅一个) |
| `<article>` | 独立文章 | 一篇博客、一条新闻 |
| `<section>` | 章节/区块 | 内容的一个逻辑分段 |
| `<aside>` | 侧边栏 | 次要内容、广告、相关链接 |
| `<footer>` | 页脚 | 版权、备案、联系方式 |

### 为什么要用语义化标签?
1. **代码可读**:别人(和未来的你)一眼看懂结构。
2. **SEO**:搜索引擎更懂你的页面。
3. **无障碍**:读屏软件能识别"这是导航""这是主内容"。

功能上 `<header>` 和 `<div>` 一样,但语义上天差地别。**现代项目都用语义化标签,你必须认识它们。**

## 一个典型页面的骨架
几乎所有网站都是这个结构,**背下来**:
```html
<body>
    <header>
        <nav> ...导航... </nav>
    </header>

    <main>
        <section> ...一块内容... </section>
        <section> ...另一块内容... </section>
    </main>

    <footer> ...页脚... </footer>
</body>
```

## 看懂真实项目的钥匙
当你打开一个陌生网页的源码,先找这几个标签,就能快速定位:
- `<header>` / `<nav>` → 顶部在哪
- `<main>` → 主内容从哪开始
- `<footer>` → 底部
- 剩下大量 `<div class="xxx">` → 靠 `class` 名字猜它是什么(下一篇 CSS 会讲 class)
