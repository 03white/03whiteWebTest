# 01 · HTML 基础

## HTML 是什么
HTML = HyperText Markup Language(超文本标记语言)。它**不是编程语言**,而是用"标签"来描述网页**结构**的语言。浏览器读 HTML,然后把它画成你看到的页面。

一句话:**HTML 负责"有什么内容"和"内容是什么角色"**(标题?段落?图片?),CSS 负责"长什么样",JavaScript 负责"能干什么"。

## 标签(tag)长什么样
```html
<p>这是一个段落</p>
```
- `<p>` 是**开始标签**
- `</p>` 是**结束标签**(多一个斜杠)
- 中间是**内容**
- 整体叫一个**元素(element)**

有些标签没有内容,叫**自闭合标签**,比如换行 `<br>`、图片 `<img>`。

## 属性(attribute)
标签可以带属性,写在开始标签里,提供额外信息:
```html
<a href="https://example.com">一个链接</a>
```
`href="..."` 就是属性:属性名 `href`,属性值 `"..."`(用引号包起来)。

## 一个完整 HTML 文档的骨架
每个 `.html` 文件都长这个样子,记住这个结构:
```html
<!DOCTYPE html>              <!-- 告诉浏览器:这是 HTML5 文档 -->
<html lang="zh-CN">          <!-- 根元素,lang 声明语言 -->
<head>                        <!-- 头部:给浏览器看的信息,不显示在页面上 -->
    <meta charset="UTF-8">    <!-- 字符编码,防止中文乱码,必写 -->
    <title>页面标题</title>    <!-- 显示在浏览器标签页上 -->
</head>
<body>                        <!-- 身体:真正显示在页面上的内容 -->
    <h1>你好,世界</h1>
</body>
</html>
```

## 关键概念:嵌套
标签可以套标签,形成"树"结构。**先开的标签后关**(像括号一样对齐):
```html
<body>
    <div>
        <p>正确嵌套</p>
    </div>
</body>
```
不要交叉:`<div><p>错</div></p>` ❌

## 注释
```html
<!-- 这是注释,浏览器不显示,用来给自己/别人做说明 -->
```
