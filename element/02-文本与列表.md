# 02 · 文本与列表

网页里最多的就是文字。这一课认识文本相关标签和列表。

## 标题 h1~h6
```html
<h1>最重要的标题</h1>
<h2>次一级</h2>
...
<h6>最小</h6>
```
- 一个页面通常**只有一个 `h1`**(页面主标题)。
- 标题表达的是**重要性层级**,不是"字大字小"。想要字大字小请用 CSS,别乱用标题。

## 段落 p
```html
<p>一段话。</p>
```
段落是块级元素:各自独占一行,上下自动有间距。

## 行内文本标签
| 标签 | 含义 | 默认样式 |
|------|------|---------|
| `<strong>` | 重要、强调 | 加粗 |
| `<em>` | 着重语气 | 斜体 |
| `<span>` | 无语义,纯占位 | 无 |
| `<br>` | 换行(自闭合) | 换行 |
| `<hr>` | 主题分隔线(自闭合) | 一条横线 |

`<span>` 很重要:它本身没样式,专门用来**包一小段文字然后用 CSS 上色/改样式**。

## 块级 vs 行内(先有个印象,CSS 篇细讲)
- **块级元素**(如 `p`、`h1`、`ul`、`div`):独占一行,从上往下堆。
- **行内元素**(如 `span`、`strong`、`a`):在一行里排,不换行。

## 列表
### 无序列表 ul(圆点)
```html
<ul>
    <li>项目一</li>
    <li>项目二</li>
</ul>
```
### 有序列表 ol(数字)
```html
<ol>
    <li>第一步</li>
    <li>第二步</li>
</ol>
```
`li`(list item)是列表项,**只能放在 `ul` 或 `ol` 里面**。

### 为什么列表很重要
真实项目里,**导航菜单几乎都是用 `ul > li` 做的**(然后用 CSS 去掉圆点、排成横的)。看别人代码时会经常遇到,记住这点。
