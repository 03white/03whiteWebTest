# 03 · 链接与图片

网页之所以叫"超文本",核心就是**链接**。加上图片,页面就有血有肉了。

## 链接 `<a>`
```html
<a href="目标地址">显示的文字</a>
```
`href`(hypertext reference)是最重要的属性,决定点击后去哪。

### href 的几种写法(重点理解路径)
| 写法 | 含义 |
|------|------|
| `href="https://xxx.com"` | 绝对地址,跳到外部网站 |
| `href="02-demo.html"` | **相对路径**,同目录下的另一个文件 |
| `href="../index.html"` | `..` 表示上一级目录 |
| `href="page/a.html"` | 下一级 `page` 目录里的文件 |
| `href="#bottom"` | **锚点**,跳到本页 `id="bottom"` 的元素 |
| `href="#"` | 回到页面顶部 |

**路径是新手最容易踩的坑**,一定要理解"相对于当前文件"的意思。

### 新标签页打开
```html
<a href="..." target="_blank">新窗口打开</a>
```

## 图片 `<img>`
```html
<img src="图片地址" alt="替代文字" width="300">
```
- `src`:图片地址(和 href 一样,支持绝对/相对路径)。
- `alt`:**必写**。图片加载失败时显示它;读屏软件念它(无障碍);对 SEO 也好。
- `width`/`height`:宽高(像素)。一般只设一个,另一个按比例自动。

`<img>` 是自闭合标签,没有 `</img>`。

## 组合技:图片当链接
把 `img` 放进 `a` 里,图片就可以点击跳转——网站 logo 常这么做:
```html
<a href="index.html">
    <img src="logo.png" alt="网站首页">
</a>
```
