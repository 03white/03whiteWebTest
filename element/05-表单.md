# 05 · 表单

表单(form)是用户**输入并提交数据**的地方:登录、注册、搜索、留言都靠它。

## 表单容器 `<form>`
```html
<form action="/submit" method="post">
    ... 各种输入控件 ...
    <button type="submit">提交</button>
</form>
```
- `action`:数据提交到哪个地址(后端接口)。
- `method`:提交方式,`get`(拼在网址上)或 `post`(放在请求体里)。
- 静态学习阶段不真正提交,`action="#"` 占位即可。

## 核心控件 `<input>`
`<input>` 靠 `type` 属性变身成各种输入框:
```html
<input type="text">      <!-- 单行文本 -->
<input type="password">  <!-- 密码,显示圆点 -->
<input type="email">     <!-- 邮箱,手机键盘会变 -->
<input type="number">    <!-- 数字 -->
<input type="radio">     <!-- 单选按钮 -->
<input type="checkbox">  <!-- 多选框 -->
<input type="date">      <!-- 日期选择器 -->
<input type="file">      <!-- 上传文件 -->
```

常用属性:
- `name`:字段名,提交时后端靠它识别(**几乎必写**)。
- `placeholder`:输入框里的灰色提示文字。
- `value`:默认值 / 单选多选的取值。
- `id`:配合 `label` 使用。

## label 与 for(重要的无障碍知识)
```html
<label for="username">用户名</label>
<input type="text" id="username">
```
`label` 的 `for` 等于 `input` 的 `id`,这样**点击文字也能聚焦到输入框**。这是好习惯,面试和真实项目都看重。

## 单选 vs 多选
- **单选 radio**:同一组 `name` 相同 → 只能选一个。
```html
<input type="radio" name="gender" value="male">男
<input type="radio" name="gender" value="female">女
```
- **多选 checkbox**:可以同时选中多个。

## 下拉 `<select>`
```html
<select name="city">
    <option value="bj">北京</option>
    <option value="sh">上海</option>
</select>
```

## 多行文本 `<textarea>`
```html
<textarea rows="4" cols="30"></textarea>
```

## 按钮 `<button>`
```html
<button type="submit">提交</button>  <!-- 提交表单 -->
<button type="reset">重置</button>   <!-- 清空表单 -->
<button type="button">普通按钮</button> <!-- 不提交,配合 JS 用 -->
```
