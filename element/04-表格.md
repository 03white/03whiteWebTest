# 04 · 表格

表格用来展示**二维数据**(行 × 列),比如课程表、价格表、数据报表。

> 注意:表格是用来展示**数据**的,**不要**用它来做页面布局(以前的老网页那么干,现在用 CSS 布局,后面会学)。

## 表格的标签层级
```html
<table>                    <!-- 整个表格 -->
    <caption>标题</caption> <!-- 可选:表格标题 -->
    <thead>                <!-- 表头区 -->
        <tr>               <!-- table row,一行 -->
            <th>列标题</th> <!-- table header,表头单元格,默认加粗居中 -->
        </tr>
    </thead>
    <tbody>                <!-- 数据区 -->
        <tr>
            <td>数据</td>   <!-- table data,普通单元格 -->
        </tr>
    </tbody>
</table>
```

记住三个核心:
- `tr` = 一**行**(table row)
- `th` = **表头**格(table header,加粗)
- `td` = 数据格(table data)

`thead` / `tbody` 是分区,让结构更清晰(可选但推荐)。

## 合并单元格
- `colspan="2"`:这个格子**横向**占 2 列。
- `rowspan="2"`:这个格子**纵向**占 2 行。

合并后,被占掉的位置就**不要再写** `td` 了(这是新手常错的点:合并后单元格数量要相应减少)。

## 关于表格线
表格默认单元格之间有缝隙、边框是双线。示例里我用了一点 CSS:
```css
table { border-collapse: collapse; } /* 合并相邻边框成单线 */
th, td { border: 1px solid #999; padding: 6px 12px; }
```
`border-collapse` 和 `padding` 都是 CSS,后面会专门学,这里先眼熟。
