# 08 · 响应式设计(媒体查询)

**响应式** = 同一个页面,在手机、平板、电脑上都好看,能自动适应屏幕宽度。这是现代网站的标配。

## 第一步:视口设置(必写!)
每个响应式页面的 `<head>` 里都要有这行:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
它告诉手机浏览器:"按设备真实宽度渲染,别缩放。"**没有这行,手机上会把页面当成缩小版的电脑页,一切响应式都失效。** 你会在所有现代网页里看到它。

## 核心工具:媒体查询 @media
根据屏幕宽度应用不同的 CSS:
```css
/* 默认样式(先写,给所有设备) */
.container { width: 1000px; }

/* 当屏幕宽度 ≤ 768px(平板及以下)时,覆盖上面 */
@media (max-width: 768px) {
    .container { width: 100%; }
}

/* 当屏幕 ≤ 480px(手机)时 */
@media (max-width: 480px) {
    .container { font-size: 14px; }
}
```
`@media (max-width: 768px) { ... }` 里的规则,**只有屏幕宽度不超过 768px 时才生效**。

## 常用断点(经验值)
| 断点 | 设备 |
|------|------|
| `max-width: 480px` | 手机 |
| `max-width: 768px` | 平板 |
| `max-width: 1024px` | 小笔记本 |
断点不是死规定,按你的设计调整即可。

## 典型套路:多列变单列
电脑上三列,手机上堆成一列——最常见的响应式需求:
```css
.cards { display: flex; gap: 16px; }        /* 电脑:横向三列 */

@media (max-width: 768px) {
    .cards { flex-direction: column; }       /* 手机:竖着堆 */
}
```

## 移动优先(mobile-first)—— 现代推荐思路
先写手机样式(简单),再用 `min-width` 往大屏加东西:
```css
.box { width: 100%; }              /* 默认:手机 */

@media (min-width: 768px) {         /* 屏幕 ≥768px 才应用 */
    .box { width: 50%; }
}
```
`min-width` 是"大于等于",`max-width` 是"小于等于",两种思路都常见,能读懂即可。

## 不用媒体查询也能响应式
回忆第 07 课那个神器,天然自适应,能少写媒体查询:
```css
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
```
以及用百分比、`max-width`、Flex 的 `flex-wrap:wrap`——现代 CSS 让"少写甚至不写媒体查询"成为可能。
