# 03 · 文本、字体与颜色单位

页面里最多的就是文字,这一课把文字调好看,并搞懂各种"单位"。

## 颜色的几种写法
```css
color: red;                /* 关键字,记几个常用的即可 */
color: #1976d2;            /* 十六进制,最常用。#RRGGBB */
color: #333;               /* 简写:#333 = #333333 */
color: rgb(25, 118, 210);  /* 红绿蓝,0~255 */
color: rgba(0, 0, 0, 0.5); /* 多个 a = 透明度 0~1,0.5 即半透明 */
```
- `color` 设**文字**颜色。
- `background-color` 设**背景**颜色。

新手记住 `#333`(深灰,比纯黑柔和,正文常用)、`#fff`(白)、`#1976d2`(蓝)这类就够起步。

## 字体相关
```css
font-size: 16px;           /* 字号 */
font-weight: bold;         /* 粗细:normal / bold / 100~900 */
font-family: "Microsoft YaHei", sans-serif; /* 字体,逗号是"备选" */
line-height: 1.6;          /* 行高,正文推荐 1.5~1.8,阅读更舒服 */
font-style: italic;        /* 斜体 */
```

`font-family` 的逗号表示"优先用前面的,没有就用后面的"。`sans-serif`(无衬线)是通用兜底。

## 文本排版
```css
text-align: center;        /* 水平对齐:left / center / right */
text-decoration: none;     /* 去掉下划线(常用于去掉链接下划线) */
text-indent: 2em;          /* 首行缩进(2em ≈ 中文两个字) */
letter-spacing: 2px;       /* 字间距 */
```

## 长度单位(重点)
| 单位 | 含义 | 什么时候用 |
|------|------|-----------|
| `px` | 像素,绝对固定 | 边框、精确尺寸 |
| `%` | 相对**父元素**的百分比 | 宽度自适应 |
| `em` | 相对**当前元素字号**的倍数 | 间距随字号缩放 |
| `rem` | 相对**根元素(html)字号**的倍数 | 整站统一缩放,现代常用 |
| `vw`/`vh` | 视口宽/高的 1% | 满屏大图、全屏区块 |

举例:根字号 16px 时,`1rem = 16px`,`2rem = 32px`。改一处 html 字号,全站按比例变——这就是 rem 受欢迎的原因。

新手阶段:**尺寸先用 px,慢慢过渡到 rem。** 心里有个印象即可。
