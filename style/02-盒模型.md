# 02 · 盒模型(Box Model)

**这是 CSS 最重要的概念,没有之一。** 理解了盒模型,你就理解了网页布局的地基。

## 核心思想:每个元素都是一个"盒子"
网页上任何一个元素(段落、图片、div……)都是一个矩形盒子。这个盒子由**从内到外 4 层**组成:

```
┌─────────────── margin(外边距) ───────────────┐
│   ┌─────────── border(边框) ───────────┐     │
│   │   ┌─────── padding(内边距) ───────┐ │     │
│   │   │                               │ │     │
│   │   │      content(内容)           │ │     │
│   │   │      width × height           │ │     │
│   │   │                               │ │     │
│   │   └───────────────────────────────┘ │     │
│   └─────────────────────────────────────┘     │
└───────────────────────────────────────────────┘
```

| 层 | 属性 | 含义 |
|----|------|------|
| 内容 | `width` `height` | 内容区域的宽高 |
| 内边距 | `padding` | 内容和边框之间的空隙(盒子**内部**的填充) |
| 边框 | `border` | 盒子的边线 |
| 外边距 | `margin` | 盒子和**其他盒子**之间的空隙 |

**一句话记忆:padding 是"内衣和身体之间",margin 是"你和别人之间"。**

## border 写法
```css
border: 5px solid #1976d2;
/*      粗细  样式   颜色    */
```
样式常见:`solid`(实线)、`dashed`(虚线)、`dotted`(点线)。

也可只设某一边:`border-bottom`、`border-top` 等。

## padding / margin 的简写(方向)
```css
padding: 20px;              /* 四个方向都是 20 */
padding: 10px 40px;         /* 上下10,左右40 */
padding: 10px 20px 30px 40px; /* 上 右 下 左(顺时针) */
```
margin 写法完全一样。单独方向:`margin-top`、`padding-left` 等。

小技巧:`margin: 0 auto;` 能让**定宽块级元素水平居中**(左右自动),常用。

## 致命坑:width 到底算不算 padding?
默认情况(`box-sizing: content-box`):
> **实际占的宽度 = width + 左右 padding + 左右 border**

比如 `width:200px; padding:20px; border:5px`,实际占 **250px**!新手经常被这个搞崩溃。

### 解决方案:box-sizing: border-box
```css
box-sizing: border-box;
```
加上它后,`width` 就是**最终宽度**,padding 和 border 会"挤进去"。这符合直觉,所以现代项目几乎都在开头写:
```css
* { box-sizing: border-box; }  /* 让所有元素都这样 */
```
**这行代码你会在无数项目里见到,现在你知道它干嘛了。**

## 神器:开发者工具
按 **F12** 打开浏览器开发者工具,选中任意元素,右下角会画出它的盒模型(蓝/绿/橙/黄四色),鼠标悬停元素时页面上也会高亮这几层。**这是学 CSS 最好的工具,一定要用起来。**
