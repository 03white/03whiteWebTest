# 05 · 显示与定位(display / position)

这一课解决"元素怎么排、放哪里"的问题,是通往布局的桥梁。

## display:元素的显示类型
### 块级 block
- 独占一行,从上往下堆。
- 能设 `width` / `height`。
- 例:`div` `p` `h1` `ul` `section`。

### 行内 inline
- 在一行里排,不换行。
- **不能**设 `width` / `height`(设了无效),上下 margin 也无效。
- 例:`span` `a` `strong`。

### 行内块 inline-block
- 像行内一样**在一行排**,又像块级一样**能设宽高**。
- 常用于横向排列的小方块(导航项、标签)。

### none
```css
display: none;  /* 彻底隐藏,不占位置 */
```
配合 JS 做"显示/隐藏"效果。

```css
div  { display: inline; }       /* 让块级变行内 */
span { display: block; }        /* 让行内变块级 */
li   { display: inline-block; } /* 让列表项横着排(做横向导航!) */
```
**用 CSS 就能改变元素的显示类型**,这是布局的常用手段。

## position:精确定位
```css
position: static;    /* 默认,正常文档流 */
position: relative;  /* 相对定位:相对"自己原来的位置"偏移 */
position: absolute;  /* 绝对定位:相对最近的"定位祖先"偏移 */
position: fixed;     /* 固定定位:相对浏览器窗口,滚动也不动 */
position: sticky;    /* 粘性定位:滚到某处就"粘住" */
```
配合 `top` / `right` / `bottom` / `left` 指定偏移量。

### 最实用的两个场景
**1. fixed 做"回到顶部"按钮 / 固定导航栏**(滚动页面它不动):
```css
.back-top {
    position: fixed;
    right: 20px;
    bottom: 20px;
}
```

**2. relative + absolute 组合:让子元素相对父元素定位**
这是经典套路——父元素设 `relative`,子元素设 `absolute`,子元素就相对父元素定位:
```css
.parent { position: relative; }             /* 父:定位参照物 */
.badge  { position: absolute; top: 0; right: 0; } /* 子:钉在父的右上角 */
```
常用于给卡片右上角贴"NEW""红点"标记。

### z-index:谁盖住谁
定位元素重叠时,`z-index` 大的在上面:
```css
z-index: 10;
```

## sticky:很好用的粘性导航
```css
.nav { position: sticky; top: 0; }
```
导航栏平时正常,滚动到顶部时"粘"在顶端不走。现代网站顶部导航常用它。
