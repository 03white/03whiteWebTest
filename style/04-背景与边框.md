# 04 · 背景与边框

学会给盒子加背景、圆角、阴影,页面立刻从"能看"变"好看"。

## 背景 background
```css
background-color: #f5f5f5;         /* 背景色 */
background-image: url("bg.jpg");    /* 背景图 */
background-size: cover;             /* 图片如何缩放 */
background-position: center;        /* 图片位置 */
background-repeat: no-repeat;       /* 是否平铺 */
```

### background-size 常用值
- `cover`:铺满整个盒子(可能裁掉一部分)——**做头图/banner 最常用**。
- `contain`:完整显示图片(可能留白)。

### 简写
```css
background: #f5f5f5 url("bg.jpg") no-repeat center / cover;
```
一行搞定,看别人代码会遇到,能读懂即可。

## 渐变背景(不需要图片)
```css
background: linear-gradient(to right, #667eea, #764ba2);
/*                          方向      起始色   结束色    */
```
方向也可以写角度:`135deg`。渐变很适合做好看的按钮和头图。

## 圆角 border-radius
```css
border-radius: 8px;      /* 四个角都圆 */
border-radius: 50%;      /* 正方形变圆形!常用于头像 */
```

## 阴影 box-shadow(让盒子"浮起来")
```css
box-shadow: 0 2px 8px rgba(0,0,0,0.15);
/*          x  y  模糊  颜色(带透明度)   */
```
- x:水平偏移,y:垂直偏移(正数往下)。
- 模糊半径:越大越柔和。
- **卡片效果的灵魂**就是这个淡淡的阴影,现代 UI 到处都是。

## 文字阴影 text-shadow(用法类似)
```css
text-shadow: 1px 1px 3px rgba(0,0,0,0.4);
```

## 综合:一张"卡片"是怎么来的
卡片 = 白底 + 圆角 + 内边距 + 阴影:
```css
.card {
    background: #fff;
    border-radius: 8px;
    padding: 20px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}
```
记住这套组合,你能复刻网上 90% 的卡片。

## 动手
打开 `04-demo.html`。试着:
1. 把头像的 `border-radius` 从 50% 改成 10px,看变化。
2. 调整卡片 `box-shadow` 的模糊值和透明度,找到你喜欢的浮起感。
3. 改渐变按钮的两个颜色。
