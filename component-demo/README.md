# Vue 组件入门训练

这套文档是给“能看懂一点 HTML/CSS，但不会独立写 Vue 组件，主要依赖 AI”的前端新人准备的。

目标不是背语法，而是做到三件事：

1. 看见一个 Vue 组件，知道每块代码在干什么。
2. AI 生成代码后，知道应该检查和修改哪里。
3. 能独立完成按钮、标签、卡片、输入框这类简单组件。

## 先认识你接手的项目

公司组件项目主要是：`D:\Project\web\web-vue3-ui-dj`。

它使用 Vue 3、TypeScript、Vite、pnpm workspace、Vant、Element Plus 和 Vitest。

现在不用一次学完这些工具。第一阶段只盯住：**Vue 组件、props、emit、slot、v-model、样式**。

## 公司项目地图

```text
web-vue3-ui-dj/
├─ apps/
│  └─ dj-ui-demo/                  # 组件演示页面：看组件怎么使用
├─ packages/
│  ├─ design-system/               # 颜色、字号、圆角等设计变量
│  ├─ vant-extra/                  # 移动端自定义组件，重点学习
│  ├─ vant-patch/                  # 修改 Vant 的主题样式
│  ├─ element-plus-extra/          # PC 端自定义组件
│  └─ element-plus-patch/          # 修改 Element Plus 的主题样式
└─ package.json                    # 项目命令和依赖
```

- `packages` 是“生产组件的工厂”。
- `apps/dj-ui-demo` 是“展示组件的商店”。
- `src/index.ts` 是“出口清单”，组件写完但没导出，其他项目就用不到。

## 正确练习方式

1. 先读文档，只理解大意，不背代码。
2. 自己敲一遍示例，不要复制粘贴。
3. 每次只改一个地方，观察页面变化。
4. 故意改坏一次，再根据报错修回来。
5. 最后让 AI 检查，但先写出你自己的判断。

## 现阶段不要做的事

- 不要直接在公司组件库里试错，先在 `component-demo` 练习。
- 不要一上来研究构建、发布、脚手架内部实现。
- 不要一次让 AI 生成一个复杂组件。
- 不要只看代码不运行。

## 第一阶段完成标准

- 能说出组件接收哪些 `props`。
- 能找出组件会 `emit` 什么事件。
- 能画出 `v-model` 的数据流。
- 能区分 `ref` 和 `computed`。
- 能找到插槽、样式、导出入口和演示页面。
