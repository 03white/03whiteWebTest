# 06 动手训练清单

这一课不是让你一次写出七个完整组件，而是让你每次只练一个 Vue 重点。

所有练习都放在 `training-project/` 中完成。先打开 [项目实战指引](07-项目实战指引.md)，再按下面的顺序练习。

每个练习开头的「这次只学什么」是一张表格。**看不懂表里的名词是正常的** —— 点右边那列的链接，[02B 核心概念原理](02B-核心概念原理.md)会讲清这个东西为什么存在、怎么用对、新手会在哪里摔。不用提前读完，卡住了再查。

## 统一规则

每个练习都按下面的顺序完成：

1. 先读目标，不让 AI 直接写完整代码。
2. 先写最小版本，让页面能显示。
3. 再增加 props、事件或插槽。
4. 每次只增加一个功能。
5. 完成后做“故意改坏”实验。
6. 最后填写复盘记录。

## 练习 1：StatusDot 静态状态点

### 这次只学什么

| 概念 | 一句话 | 不懂就点 |
|---|---|---|
| 组件文件 | 一个 `.vue` 分 script、template、style 三块 | [02](02-Vue组件必会知识.md#vue-文件的三块) |
| props | 父组件递进来的材料，你只能看不能改 | [原理](02B-核心概念原理.md#props) |
| 联合类型 | 只准填 success / warning / error 这三个词 | [原理](02B-核心概念原理.md#联合类型) |
| 动态 class | 让 class 跟着数据变，样式才会跟着状态变 | [原理](02B-核心概念原理.md#动态-class) |
| scoped 样式 | 样式只管自己这个组件，别漏到隔壁 | [原理](02B-核心概念原理.md#scoped) |

### 文件位置

```text
training-project/src/components/StatusDot/StatusDot.vue
training-project/src/views/StatusDotDemo.vue
```

### 功能要求

- 接收 `status` 属性。
- `status` 只能是 `success`、`warning`、`error`。
- 三种状态显示三种颜色。
- 不需要事件。
- 不需要内部状态。

### 使用方式

```vue
<StatusDot status="success" />
<StatusDot status="warning" />
<StatusDot status="error" />
```

### 推荐实现顺序

1. 先写一个圆形 `span`。
2. 给它加基础尺寸和圆角。
3. 用 `defineProps` 接收 `status`。
4. 用动态 class 根据状态切换颜色。
5. 在 demo 页面中同时显示三种状态。

### 完成标准

- 父组件传入不同 `status` 时，颜色会变化。
- `status` 的类型不会随便接受任意字符串。
- 组件没有写死某一种状态。
- 样式只影响当前组件。

### 故意改坏

- 把 `status` 改成 `warning`，观察颜色变化。
- 把动态 class 拼错，观察样式为什么失效。
- 删除 `scoped`，再创建另一个同名样式，观察影响范围。

```text
training-project/src/views/StatusTagDemo.vue
```

### 功能要求

- `text?: string`，默认值为空字符串。
- `type?: 'success' | 'warning' | 'error'`，默认值为 `success`。
- `plain?: boolean`，默认值为 `false`。
- `disabled?: boolean`，默认值为 `false`。
- 支持默认插槽，插槽内容优先于 `text`。
- 非禁用状态点击时触发 `click` 事件。
- 禁用状态不能触发 `click`。

### 使用方式


### 推荐实现顺序

1. 先显示 `text`。
2. 再加 `type` 和 `plain` 的 class。
3. 再加入默认插槽。
4. 再定义 `click` 事件。
5. 最后处理 `disabled` 的样式和行为。

### 完成标准

- 不传参数时有合理的默认效果。
- 插槽内容能替换 `text`。
- 普通状态可以点击，禁用状态不能点击。
- `click` 事件能把原始鼠标事件传给父组件。

## 练习 3：CountButton 计数按钮

### 这次只学什么

| 概念 | 一句话 | 不懂就点 |
|---|---|---|
| `ref` | 会变的数据，包一层 Vue 才知道要重画页面 | [原理](02B-核心概念原理.md#ref) |
| `.value` | script 里要写，template 里不要写 | [原理](02B-核心概念原理.md#ref) |
| 事件参数 | `emit` 要带上最新值，不然父组件只知道"变了" | [原理](02B-核心概念原理.md#为什么要带参数) |
| 非受控 | `count` 存在组件自己身上，父组件不插手 | [原理](02B-核心概念原理.md#受控组件) |
| 禁用状态 | 这次重点练第 2 层：事件里 `return` 拦住 | [原理](02B-核心概念原理.md#禁用状态) |

### 文件位置

```text
training-project/src/components/CountButton/CountButton.vue
training-project/src/views/CountButtonDemo.vue
```

### 功能要求

- 内部使用 `ref` 保存 `count`。
- 初始值为 `0`。
- 每次点击加 `1`。
- 点击后触发 `change` 事件，并传出最新数字。
- `disabled` 为 `true` 时不能加数，也不能触发 `change`。

### 使用方式

```vue
<CountButton @change="handleChange" />
```

```ts
function handleChange(value: number) {
  console.log('最新次数：', value)
}
```

### 完成标准

- 页面能显示当前次数。
- 每次点击只增加一次。
- 父组件能收到最新次数。
- 禁用后点击没有任何变化。

### 故意改坏

- 把 `emit('change', count.value)` 改成 `emit('change')`，看父组件收到什么。
- 把禁用判断删掉，观察禁用按钮为什么仍然会加数。
- 在模板和函数中各触发一次事件，观察一次点击为什么收到两次。

## 练习 5：BaseSwitch 开关组件

### 这次只学什么

先理解普通事件，再理解 `v-model`。这两个阶段写出来的东西**功能完全一样**，差别只在调用方少写了多少字。

| 概念 | 一句话 | 不懂就点 |
|---|---|---|
| 普通事件写法 | 第一阶段先手写 `:checked` + `@change` 两半 | [原理](02B-核心概念原理.md#emit-与事件参数) |
| `v-model` | 第二阶段换成糖，它就等于上面那两半 | [原理](02B-核心概念原理.md#v-model) |
| 受控组件 | 值是父组件的，子组件只能报上去、不能自己存 | [原理](02B-核心概念原理.md#受控组件) |
| 动态 class | 开 / 关两种外观靠 class 切换 | [原理](02B-核心概念原理.md#动态-class) |

### 文件位置

```text
training-project/src/components/BaseSwitch/BaseSwitch.vue
training-project/src/views/BaseSwitchDemo.vue
```

### 第一阶段：先不用 v-model

先实现：

```vue
<BaseSwitch :checked="enabled" @change="enabled = $event" />
```

要求：接收 `checked: boolean`，接收 `disabled?: boolean`，点击后触发 `change` 并传出相反的 boolean，禁用时不能切换。

### 第二阶段：改成 v-model

再支持：

```vue
<BaseSwitch v-model="enabled" />
```

理解：

```text
v-model
等价于
:model-value="enabled" @update:model-value="enabled = $event"
```

### 完成标准

- 点击开关后，页面状态会切换。
- 父组件能拿到最新 boolean。
- `v-model` 能正常工作。
- 禁用状态不能切换。

## 练习 6B：增加清空能力

新概念：`clearable` 默认值是 `true`，属于[布尔默认值的例外情况](02B-核心概念原理.md#默认值)；清空要 emit 空字符串 `''` 而不是 `null`，原因见[原生 input](02B-核心概念原理.md#原生-input)最后一条。

在 6A 的基础上增加：

- `clearable?: boolean`，默认值为 `true`。
- 有内容且允许清空时显示清空按钮。
- 点击清空按钮后，值变为空字符串。
- 清空时触发 `clear` 事件。
- 禁用或只读时不能清空。

## 练习 6C：增加字数和焦点事件

新概念：字数 `3/20` 里的 `3` 要用 `computed` 算，不要用 `ref` 另存一份 —— 理由见 [ref 第 2 条](02B-核心概念原理.md#ref)。

在 6B 的基础上增加：

- `maxlength?: number`。
- 显示当前字数，例如 `3/20`。
- 触发 `focus` 事件。
- 触发 `blur` 事件。
- 超过最大长度时，行为要与需求保持一致，并写在复盘中。

## 每个练习的 AI 使用方式

### 第一次：只问思路

```text
请根据下面的需求，列出组件需要的 props、事件、插槽和内部状态。
先不要写代码，也不要增加需求之外的功能。
```

```text
请只实现当前练习要求的最小版本。
使用 Vue 3、<script setup lang="ts"> 和 scoped 样式。
请按文件分别输出，并解释每个文件的职责。
```

```text
请只审查，不要重写整个组件。

```
