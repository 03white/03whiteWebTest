# 06 动手训练清单

这一课不是让你一次写出七个完整组件，而是让你每次只练一个 Vue 重点。

所有练习都放在 `training-project/` 中完成。先打开 [项目实战指引](07-项目实战指引.md)，再按下面的顺序练习。

## 统一规则

每个练习都按下面的顺序完成：

1. 先读目标，不让 AI 直接写完整代码。
2. 先写最小版本，让页面能显示。
3. 再增加 props、事件或插槽。
4. 每次只增加一个功能。
5. 完成后做“故意改坏”实验。
6. 最后填写复盘记录。

## 练习 1：StatusDot 静态状态点

### 这次只学什么

学习组件文件、props、联合类型、动态 class 和 scoped 样式。

### 文件位置

```text
training-project/src/components/StatusDot/StatusDot.vue
training-project/src/views/StatusDotDemo.vue
```

### 功能要求

- 接收 `status` 属性。
- `status` 只能是 `success`、`warning`、`error`。
- 三种状态显示三种颜色。
- 不需要事件。
- 不需要内部状态。

### 使用方式

```vue
<StatusDot status="success" />
<StatusDot status="warning" />
<StatusDot status="error" />
```

### 推荐实现顺序

1. 先写一个圆形 `span`。
2. 给它加基础尺寸和圆角。
3. 用 `defineProps` 接收 `status`。
4. 用动态 class 根据状态切换颜色。
5. 在 demo 页面中同时显示三种状态。

### 完成标准

- 父组件传入不同 `status` 时，颜色会变化。
- `status` 的类型不会随便接受任意字符串。
- 组件没有写死某一种状态。
- 样式只影响当前组件。

### 故意改坏

- 把 `status` 改成 `warning`，观察颜色变化。
- 把动态 class 拼错，观察样式为什么失效。
- 删除 `scoped`，再创建另一个同名样式，观察影响范围。

## 练习 2：StatusTag 标签组件

### 这次只学什么

学习默认值、默认插槽、事件、禁用状态和联合类型。

### 文件位置

```text
training-project/src/components/StatusTag/StatusTag.vue
training-project/src/views/StatusTagDemo.vue
```

### 功能要求

- `text?: string`，默认值为空字符串。
- `type?: 'success' | 'warning' | 'error'`，默认值为 `success`。
- `plain?: boolean`，默认值为 `false`。
- `disabled?: boolean`，默认值为 `false`。
- 支持默认插槽，插槽内容优先于 `text`。
- 非禁用状态点击时触发 `click` 事件。
- 禁用状态不能触发 `click`。

### 使用方式

```vue
<StatusTag text="已完成" type="success" />
<StatusTag text="处理中" type="warning" plain />
<StatusTag type="error">
  自定义文字
</StatusTag>
```

### 推荐实现顺序

1. 先显示 `text`。
2. 再加 `type` 和 `plain` 的 class。
3. 再加入默认插槽。
4. 再定义 `click` 事件。
5. 最后处理 `disabled` 的样式和行为。

### 完成标准

- 不传参数时有合理的默认效果。
- 插槽内容能替换 `text`。
- 普通状态可以点击，禁用状态不能点击。
- `click` 事件能把原始鼠标事件传给父组件。

## 练习 3：CountButton 计数按钮

### 这次只学什么

学习 `ref`、点击函数、`emit` 和事件参数。

### 文件位置

```text
training-project/src/components/CountButton/CountButton.vue
training-project/src/views/CountButtonDemo.vue
```

### 功能要求

- 内部使用 `ref` 保存 `count`。
- 初始值为 `0`。
- 每次点击加 `1`。
- 点击后触发 `change` 事件，并传出最新数字。
- `disabled` 为 `true` 时不能加数，也不能触发 `change`。

### 使用方式

```vue
<CountButton @change="handleChange" />
```

```ts
function handleChange(value: number) {
  console.log('最新次数：', value)
}
```

### 完成标准

- 页面能显示当前次数。
- 每次点击只增加一次。
- 父组件能收到最新次数。
- 禁用后点击没有任何变化。

### 故意改坏

- 把 `emit('change', count.value)` 改成 `emit('change')`，看父组件收到什么。
- 把禁用判断删掉，观察禁用按钮为什么仍然会加数。
- 在模板和函数中各触发一次事件，观察一次点击为什么收到两次。

## 练习 4：BaseCard 卡片组件

### 这次只学什么

学习默认插槽、具名插槽、prop 和布局。

### 文件位置

```text
training-project/src/components/BaseCard/BaseCard.vue
training-project/src/views/BaseCardDemo.vue
```

### 功能要求

- `title?: string`。
- `shadow?: boolean`，默认值为 `true`。
- 支持默认插槽作为卡片内容。
- 支持 `title` 插槽替换标题。
- 支持 `footer` 插槽显示底部内容。
- `shadow` 为 `true` 时显示阴影，为 `false` 时不显示。

### 使用方式

```vue

  <p>卡片内容</p>

  <template #footer>
    <button>确定</button>
  </template>
</BaseCard>
```

### 完成标准

- 不传 `title` 时不会显示空标题区域。
- 默认插槽内容显示在卡片主体。
- `title` 和 `footer` 插槽可以替换或补充内容。
- `shadow` 能控制阴影。

## 练习 5：BaseSwitch 开关组件

### 这次只学什么

先理解普通事件，再理解 `v-model`。

### 文件位置

```text
training-project/src/components/BaseSwitch/BaseSwitch.vue
training-project/src/views/BaseSwitchDemo.vue
```

### 第一阶段：先不用 v-model

先实现：

```vue
<BaseSwitch :checked="enabled" @change="enabled = $event" />
```

要求：接收 `checked: boolean`，接收 `disabled?: boolean`，点击后触发 `change` 并传出相反的 boolean，禁用时不能切换。

### 第二阶段：改成 v-model

再支持：

```vue
<BaseSwitch v-model="enabled" />
```

理解：

```text
v-model
等价于
:model-value="enabled" @update:model-value="enabled = $event"
```

### 完成标准

- 点击开关后，页面状态会切换。
- 父组件能拿到最新 boolean。
- `v-model` 能正常工作。
- 禁用状态不能切换。

## 每个练习的 AI 使用方式

### 第一次：只问思路

```text
请根据下面的需求，列出组件需要的 props、事件、插槽和内部状态。
先不要写代码，也不要增加需求之外的功能。
```

### 第二次：让 AI 写最小版本

```text
请只实现当前练习要求的最小版本。
使用 Vue 3、<script setup lang="ts"> 和 scoped 样式。
请按文件分别输出，并解释每个文件的职责。
```

### 第三次：让 AI 审查自己的代码

```text
请只审查，不要重写整个组件。
请按 props、事件、v-model、slot、disabled、样式和文件位置检查。
每个问题说明原因，并给出最小修改方式。
```
