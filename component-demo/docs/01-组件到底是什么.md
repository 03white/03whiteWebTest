# 01 组件到底是什么

## 一句话理解

组件就是一块可以反复使用的页面零件。

按钮、标签、输入框、弹窗都是组件。它们不是“写死的页面”，而是可以通过参数改变外观和行为的零件。

```vue
<MyButton text="保存" type="primary" />
<MyButton text="删除" type="danger" />
```

这里用了同一个按钮组件，只是传入的数据不同。

## 一个组件只需要想清四件事

### 1. 它长什么样

由 `template` 和 CSS 决定。

### 2. 外部能传什么

用 `props` 接收。

```vue
<MyTag text="已完成" color="green" />
```

### 3. 用户操作后通知什么

用 `emit` 发事件。

```vue
<MyButton @click="save" />
```

按钮不负责真正保存数据。它只通知外面：“我被点了”。真正保存什么，由使用按钮的页面决定。

### 4. 外部能塞入什么内容

用 `slot` 留位置。

```vue
<MyCard>
  <p>这段内容由使用者决定</p>
</MyCard>
```

`MyCard` 只负责边框、圆角和布局，中间内容交给外部。

## 最重要的组件思维

写组件不是先写代码，而是先划清责任。

以确认弹窗为例：

- 弹窗负责：显示标题、内容、按钮，发出确认和取消事件。
- 页面负责：是否显示弹窗，确认后调用哪个接口。

如果弹窗内部直接写“删除用户接口”，它就很难用于其他业务。

## 什么时候适合拆组件

满足任意两条，可以考虑抽成组件：

- 同样的结构出现两次以上。
- 外观基本相同，只是文字、颜色、状态不同。
- 有独立行为，例如打开、关闭、选择、清空。
- 页面代码太长，某块内容可以单独命名。
- 需要被多个项目共同使用。

不要为了“看起来高级”把每个 `div` 都拆成组件。拆分的目的应该是：**更好懂、更好改、更能复用**。

## 组件的输入和输出

```text
props / slot / v-model
          ↓
       组件内部
          ↓
emit / 页面显示结果
```

- `props`：外面给组件的设置。
- `slot`：外面放进组件的自定义内容。
- `v-model`：外面和组件共同维护的值。
- `emit`：组件通知外面发生了什么。

读任何组件时，都先找这四样东西。

## 小练习

先不写代码，给“状态标签”设计接口：

```text
组件名：StatusTag
输入：文字、状态、是否显示圆点
输出：无
插槽：可以让外部替换文字
状态：success / warning / error
```

先写清单，再让 AI 写代码，生成结果会稳定很多。
