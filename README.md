# 原生前端学习路线（HTML + CSS）

目标:学完之后能**看懂**任何原生前端静态项目的结构和样式。

## 目录约定
- `element/` — HTML(结构)相关:每课一份 `.md` 讲解 + 一份 `.html` 示例。
- `style/` — CSS(样式)相关:每课一份 `.md` 讲解 + 一份 `.css`/`.html` 示例。
- `project/` — 最终综合项目(个人主页),把所有知识点串起来。

## 怎么学(重要)
1. 先读当课的 `.md`,理解概念。
2. 用浏览器打开对应的 `.html`(直接双击即可),对照代码看效果。
3. 动手改代码,看页面怎么变——**改坏了再改回来**是最快的学习方式。
4. 每学完一个 CSS 知识点,回到之前的 HTML 页面给它加样式。
